# ระบบส่งรายงานนักเรียนไป Google Sheets

โฟลเดอร์นี้เป็นต้นฉบับ Google Apps Script ที่ใช้คู่กับเว็บใน VS Code โดยรับข้อมูลความคืบหน้าจากเว็บ แล้วเพิ่มหรืออัปเดตนักเรียนตามรหัสใน Google Sheet เดิม

ข้อมูลที่ส่งประกอบด้วยคะแนน รางวัล จุดที่เรียนค้าง ความพยายามของกิจกรรม 1.1–1.4 เกณฑ์ผ่านรายบท จำนวนและคำถามล่าสุดที่ส่งให้น้องชวนคิด เวลาเข้าใช้ และจำนวนครั้งที่เข้า ระบบหลักยังบันทึกข้อมูลฉบับเต็มใน Supabase ส่วน Google Sheet เป็นตารางสำรองสำหรับครู

เมื่อต้องอัปเดต Web App ให้เปิด Google Sheet ของครู เลือก **ส่วนขยาย → Apps Script** แล้วแทนที่ `Code.gs` ด้วยไฟล์นี้ จากนั้นเลือก **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** โดยคง URL ของ Web App เดิมไว้
